# M16: точная замена степенного условия производной

Дата: 10 сентября 2026, America/Los_Angeles.
Продолжение `B-PKC-M16-COMPLETE-COST-BRIDGE`, исходный архив `M16_next_100_nodes_2026-09-10.zip`.

## Результат

В общей нормовой карте можно заменить `g | F^q` на `g | F*g'` без потери повторений, знаков или GLV-фаз, если характеристика поля больше q. При квадратсвободном F новая система в коэффициентах g имеет невырожденный якобиан в каждом решении, в том числе при кратных корнях g. На допустимой нормовой карте ее якобиан по q-1 свободным параметрам имеет полный столбцовый ранг. Это доказанный ниже локальный структурный результат, а не оценка стоимости глобального поиска.

Проведены точные проверки на всех 5043 выбранных малых монических полиномах; все 57 допустимых точек поддержки имели полный ранг. На 24 ранее построенных 256-битных сертификатах проверены новая система, детерминант и ранги. Для q=16 с различными координатами новый ранг равен 15, старый степенной равен 0. Все 15 столбцов этого примера независимо сверены прямым дифференцированием вычислений через двойственные числа.

Есть новые поисковые ответы для независимо выбранных малых целей q=4. Ни один из 256-битных случаев не является поиском неизвестного разложения: они явно взяты из старой серии PLANTED. Главный барьер не закрыт.

## 1. Исходная нормовая карта

Пусть `p>q`, q четно, `s=q/2`, `E:y²=x³+7`, `R=(r,z)`, `z!=0`, и r не принадлежит корневому множеству исходного `X^D-1`. Для secp256k1 `q=16`, `D=564522`, `p=2^256-2^32-977`.

Параметры карты:

```
deg a <= s
b monic, deg b=s-1
a(r)=z*b(r)
g=((X^3+7)*b^2-a^2)/(X-r)
deg g=q, g monic
gcd(g,b)=1
```

Полином F задает допустимые координаты: либо `F=X^D-1`, либо `F=F_U=J(X^3)`, где все корни F_U поднимаются в рациональные ненулевые по y точки. На secp256k1 оба F не имеют общих корней с `X^3+7`. Параметры a,b сохраняются, координаты не заменяются независимыми кубами. Из корня alpha восстанавливается `y=-a(alpha)/b(alpha)`.

Входной архив использовал общий критерий `g | F^q`, а отдельная ветвь различных x использовала `g | F`. Новый критерий заменяет первый, но не объявляется обязательным улучшением второго.

## 2. Теорема о поддержке с кратностями

Пусть k поле характеристики 0 или p>q, g монический степени q. Тогда:

```
g | F^q  <=>  все корни g являются корнями F  <=>  g | F*g'.
```

В первом переходе любая кратность корня g не больше q. Для последнего перехода рассмотрим корень alpha кратности e. Так как `1<=e<=q<p`, производная g имеет там порядок ровно e-1. У F*g' порядок не меньше e ровно тогда, когда F(alpha)=0. Это применимо и над алгебраическим замыканием.

Эквивалентная классическая формулировка: `g/gcd(g,g') | F`. Производная используется для удаления кратности при проверке поддержки, но кратные точки из самого g не удаляются. Классический факт об отделении квадратсвободной части и условии `deg g<p` изложен в источнике S1; общая идея не заявляется новой.

### Необходимость условия на характеристику

Над F_3 возьмем `g=X^3`, `F=X-1`. Тогда g'=0, и критерий с производной принимает g, хотя его корень 0 недопустим. Исходный критерий `g | F^3` правильно отвергает этот случай. Контрпример включен в тесты, поэтому условие p>q нельзя молча убрать.

### Формальные степени по X

Для настоящего пригодного F_U степени 283527 и q=16:

```
deg(F_U^16) = 4536432
deg(F_U*g') = 283542
```

Для исходного двучлена:

```
deg((X^564522-1)^16) = 9032352
deg((X^564522-1)*g') = 564537
```

Это степени по X до взятия остатка. Они НЕ являются solving degree, количеством операций, потребляемой памятью или коэффициентом ускорения. Старую степень можно вычислять схемой повторных квадратов без полного раскрытия; такой контроль не исключен из сравнения.

## 3. Теорема о невырожденности системы поддержки

Зафиксируем квадратсвободный F. Рассмотрим q коэффициентов остатка

```
S(g) = rem(F*g',g)
```

как полиномиальное отображение из q коэффициентов монического g в k^q. Деление на монический g корректно в кольце параметров и не вводит знаменателей.

В решении положим `H=F*g'/g`. Для вариации h степени меньше q линейная часть равна

```
dS_g(h) = rem(F*h' - H*h, g).
```

Если `g=product (X-alpha_i)^e_i`, то китайская теорема об остатках разбивает `k[X]/g` на локальные кольца. В локальном параметре `T=X-alpha_i`:

```
F=F'(alpha_i)*T+O(T^2)
H=e_i*F'(alpha_i)+O(T)
```

На последовательных степенях `T^j`, `0<=j<e_i`, оператор имеет диагональные коэффициенты

```
(j-e_i)*F'(alpha_i).
```

Все они ненулевые. Значит `rank dS_g=q` во всех решениях, в том числе при повторяющихся корнях g. Более точно:

```
det dS_g = (-1)^q * product_i(e_i! * F'(alpha_i)^e_i).
```

Для `F=X^D-1`, alpha_i^D=1, получаем удобную конкретную формулу:

```
det dS_g = D^q * product_i(e_i!) / g(0)  mod p.
```

Она проверена на всех 24 старых 256-битных сертификатах.

Следствие: пространство монических g с поддержкой в корнях F имеет в этой записи только приведенные изолированные точки. Если F имеет L различных корней над замыканием, число этих точек равно `binomial(L+q-1,q)`. Это число мультимножеств, не число разложений фиксированной цели.

## 4. Полный ранг в нормовых параметрах

В нормовой карте имеется q-1 свободный параметр. Линеаризация карты `parameters -> g` имеет вид

```
delta_g = 2*((X^3+7)*b*delta_b - a*delta_a)/(X-r).
```

Покажем отсутствие ядра на допустимом решении. У a и b нет общего корня: он дал бы одновременно a=b=0 и кратный корень нормы, что невозможно вне поддержки g и r, а в поддержке исключено `gcd(g,b)=1`; в r это противоречит g(r)!=0. Также a и `X^3+7` взаимно просты: общий корень был бы рамированным корнем нормы, не принадлежащим ни поддержке F, ни r. Следовательно, `gcd(a,(X^3+7)*b)=1`.

Если delta_g=0, то `(X^3+7)*b*delta_b=a*delta_a`. Отсюда `(X^3+7)*b | delta_a`. Но степень делителя s+2, а `deg delta_a<=s`. Поэтому delta_a=0, затем delta_b=0. Отображение вариаций имеет ранг q-1.

Составляя с обратимым `dS_g`, получаем:

```
rank Jacobian(rem(F*g',g) в нормовых параметрах) = q-1.
```

Для M16 это ранг 15. Утверждение относится к допустимым решениям и перечисленным невырожденным условиям. Оно не объявляет весь несатурированный идеал с посторонними общими корнями a,b приведенным. Условие `gcd(g,b)=1` остается обязательным.

## 5. Почему степенная запись искусственно вырождена

Для старого отображения `P(g)=rem(F^q,g)` в решении:

```
dP_g(h)=-rem((F^q/g)*h,g).
```

Если g квадратсвободен и g|F, то при q>=2 полином F^q/g делится на g. Поэтому якобиан P тождественно нулевой, как и его композиция с нормовой картой. Более общо, это верно, если каждая кратность g не больше q/2.

Вырожденность здесь относится к системе уравнений в параметрах. Ее нельзя путать с кратностью координатного корня g. Новая система может быть регулярной даже при `g=(X-alpha)^q`.

Старая запись не всегда имеет нулевой ранг. На случаях одной q-кратно повторенной точки старый ранг также q-1. Все эти исключения сохранены в результатах, а не отобраны только случаи выгодного контраста.

На отдельной квадратсвободной ветви старое условие `g|F` уже не имело рассматриваемого q-кратного утолщения. Настоящий результат относится прежде всего к общей карте с повторениями.

## 6. Вычислительные проверки

### Полная малая проверка теоремы поддержки

Проверены все 5043 выбранных монических полинома:

- F_5, степени 1..4, корни F={1,2}: 780 полиномов;
- F_7, степени 1..4, корни F={0,1,3}: 2800 полиномов;
- F_11, степени 1..3, корни F={2,5}: 1463 полинома.

В каждом случае сравнивались степенной критерий, производная и отдельное удаление всех допустимых линейных множителей. Совпадение полное; якобианы во всех 57 положительных случаях имеют полный ранг. Это конечные проверки; общая теорема опирается на доказательство выше.

### Настоящее 256-битное поле, но заранее построенные ответы

Взяты все 24 прежних PLANTED-сертификата: q=2,4,...,16; различные точки, одна повторенная точка, две повторенные точки. Их содержание заново проверено независимой проективной арифметикой и SymPy. Затем для F=X^D-1 вычислены остатки, якобианы и детерминанты.

Для трех M16-образцов:

| Шаблон | Новый ранг | Старый ранг |
|---|---:|---:|
| 16 различных координат | 15 | 0 |
| Одна точка повторена 16 раз | 15 | 15 |
| Две точки с кратностями | 15 | 0 |

Все 15 столбцов первого M16-образца независимо проверены двойственными числами, то есть прямым дифференцированием последовательности повторных квадратов и редукций, без использования формулы `F*h'-H*h` для получения производной.

Ни один из этих 24 случаев не является новым целевым поиском. Плотный J заново не строился, а его 94510 коэффициентов не использовались в данной 256-битной проверке. Общая теорема применима и к F_U.

### Новый поиск на малых целях

План выбирает цель по SHA256 из всех аффинных точек, независимо от факторбазы, до поиска. Решатель получает только p,D,q,R. Затем отдельно сравнивается полное множество найденных решений со всеми допустимыми мультимножествами. Перечисление валидатора не передается решателю.

Результаты и точные локальные времена хранятся в `results/probe_*.json`, все незавершенные запуски в `benchmark_runlog.json`. Полнота проверяется для общей нормовой карты без противоположных пар, включая повторенные точки, а не только для различных x.

На F_97,D=3,q=4 завершены четыре разные цели: одна без решения и три с единственным ответом каждая. Все три ответа содержат повторения. Это намеренно трудная для прежней квадратсвободной ветви проверка полноты, а не свидетельство решения сложной криптографической задачи. Два ответа имеют вид 4P=R и допускают простой групповой контроль; их нельзя рекламировать как достижение нового быстрого ECDLP-алгоритма.

Один и тот же экземпляр R=(17,19) сравнен двумя общими кодировками:

- `rem(F^4,g)=0`: четыре входных уравнения степени 18;
- `rem(F*g',g)=0`: четыре входных уравнения степени 6.

Новая запись завершилась с корректным ответом; старая не завершилась в 60-секундном бюджете всего дочернего процесса. Это цензурированное наблюдение, не точный коэффициент ускорения и не формальное равновероятностное сравнение практических методов ECDLP. Проверено также явное частное `F*g'=H*g`, которое вводит дополнительные переменные и дает степень не выше 3, но само по себе не гарантирует меньшую стоимость.

Более крупные контрольные случаи q4 с двумя GLV-орбитами и q6 также запускались; их фактический статус сохранен в журнале. Тайм-аут не означает отсутствия решения и не является математическим отрицательным результатом.

## 7. Что меняется в дальнейшем исследовании

Для общей карты с кратностями разумно сравнивать:

```
rem((X^D-1)*g',g)=0
rem(J(X^3)*g',g)=0
```

с отдельной квадратсвободной ветвью `g|F_U`, не смешивая их покрытия. Знаки и GLV-фазы остаются в a,b,g.

Структурный дефект степенной записи устранен точно. Но полный ранг в неизвестном решении не дает способа добраться до этого решения. В конечном поле нет автоматической гарантии сходимости метода Ньютона от случайного старта. Размер глобального исключения, стоимость одной компоненты, вероятность успеха и сравнение полной процедуры с общими алгоритмами все еще требуют работы.

`B-PKC-M16-COMPLETE-COST-BRIDGE` остается открытым. Новые утверждения в Lean не формализованы; GitHub не изменялся. Расходы поиска нельзя подменять числом параметров, степенью по X или локальным рангом.
