# Воспроизводимый M16-проход

Основной текст: `RESEARCH_NOTE_RU.md`.

Основные программы используют только стандартную библиотеку Python 3.10+.

Запуск из этой папки:

```text
python previous/verify_m16_factorbase.py
python exact_cost_bounds.py
python toy_yield_and_search.py
python permutation_cost_certificate.py
python toy_end_to_end.py
python validate_independent.py
```

Первый скрипт повторно пересчитывает исходную факторбазу. Его сохранённый stdout: `factorbase_replay.json`.

`validate_independent.py` не импортирует программы-производители. Он использует другую формулу подсчёта коэффициентов и проективную арифметику вместо аффинной, проверяет 319 разложений и 9 восстановлений скаляра.

`select_toys.py` нужен только для повторения исходного выбора малых полей, требует SymPy. Сами основные проверки простоты реализованы без него. Журнал выбора: `toy_selection.json`.

Нет сетевых обращений, закрытых ключей третьих лиц, автоматического изменения GitHub, запуска облачных платных задач или заявленного решения 256-битного ECDLP. Скаляры внутри тестов синтетические. PLANTED-свидетель применяется только к утверждению о перестановках, никогда к оценке вероятности успеха на случайной цели.

Результаты конечных проверок не являются Lean-доказательствами, оценкой solving degree или свидетельством асимптотического ускорения. Файлы `*.json` содержат полные параметры, результаты, ограничения и проверяемые свидетели. Поля времени характеризуют эту среду и не экстраполируются на пользовательский компьютер.
