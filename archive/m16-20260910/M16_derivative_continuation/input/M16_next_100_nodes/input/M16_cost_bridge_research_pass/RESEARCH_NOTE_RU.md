# M16: стоимость и частота разложений

Дата: 2026-09-10. Состояние: локальный исследовательский проход, не Lean-сертификат и не изменение репозитория.

Исходный код проекта прочитан на коммите `e887029e21a5b97c05372b63b53f2d341ad15bda` репозитория `KeyAIGit/ecdlp-lean-verification`. Узел: `B-PKC-M16-COMPLETE-COST-BRIDGE`.

## Вывод

Быстрый алгоритм получения M16-разложения независимо заданной точки secp256k1 не получен. Выполнены точные арифметические расчёты, получены ограничения для конкретных способов поиска, проведены исчерпывающие проверки покрытия на малых кривых и испытан контрольный поиск столкновений 8+8. В девяти малых конфигурациях проверено восстановление тестового скаляра из настоящих найденных соотношений. Три остальные конфигурации не дали достаточно соотношений в зафиксированном бюджете.

Это не измерение solving degree, не реализация полного полиномиального решателя PKC, не оценка сложности secp256k1 по малым кривым. Статус основного барьера остаётся открытым.

## 1. Исходные числа

p = 2^256 - 2^32 - 977.

n = 0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEBAAEDCE6AF48A03BBFD25E8CD0364141.

D = 564522 = 2 * 3 * 7 * 13441.

H = {x : x^D = 1}. A = {(x,y) : x in H, y^2 = x^3+7}.

Прежний скрипт повторно выполнен двумя способами: критерий Эйлера на образе кубирования и символ Якоби на всей подгруппе. Получено 283527 пригодных x, 567054 подписанных точек, 94509 шеститочечных орбит GLV и смены знака. Важно различать размер поля p и порядок группы n.

## 2. Точное ограничение покрытия

Определим delta_m = |mA|/n для равномерной цели, где повторения слагаемых разрешены.

Без использования GLV:

    delta_m <= min(1, binomial(|A|+m-1,m)/n).

Доказательство: любое упорядоченное разложение задаёт мультимножество размера m; каждое мультимножество задаёт одну сумму. Разные мультимножества могут давать одну точку, поэтому подсчёт даёт верхнюю, а не нижнюю границу.

Более точная нормализация известных симметрий:

Выберем B=94509 представителей шеститочечных орбит. Формальные коэффициенты каждой орбиты лежат в Z[w]/(w^2+w+1). Шесть элементов орбиты соответствуют шести единицам +/-1, +/-w, +/-w^2. Число коэффициентов минимального веса r равно 6r для r>=1; при r=0 число равно 1. Следовательно, производящая функция одной орбиты:

    theta(t) = 1 + 6t/(1-t)^2 = (1+4t+t^2)/(1-t)^2.

Число формальных векторов коэффициентов общего минимального веса не более m:

    K_m = [t^m] (1+4t+t^2)^B / (1-t)^(2B+1).

При m>=2 образ этих векторов в группе совпадает с mA. Для ненулевого коэффициента любое представление можно удлинить на один шаг, заменив единицу суммой двух других единиц. Нулевой вектор дополняется нулевыми суммами длины 2 и 3. Для m=1 используем K_1=6B, не включая ноль.

Таким образом:

    delta_m <= min(1,K_m/n).

Это не предполагает независимости представителей орбит. Любые дополнительные соотношения между ними могут лишь уменьшить размер образа. Векторы считаются формальными; равенство их образов не означает их тождественности.

Два независимых вычисления K_m: биномиальное разложение и рекурсия логарифмической производной. Для f_k=[t^k] theta(t)^B/(1-t):

    (k+1)f_(k+1) = (6B+1-3k)f_k + (6B+3k+1)f_(k-1) + (k-1)f_(k-2),
    f_0=1, f_negative=0.

Результаты K_m/n:

- m=13: 8.690579035429138e-13;
- m=14: 3.519864537451805e-8;
- m=15: 0.0013305721566581191;
- m=16: 47.15422998115776.

Последнее число является точным средним количеством формальных нормализованных векторов на равномерную цель, а не вероятностью успеха. Граница delta_16<=1 неинформативна. Даже среднее 47.15 не доказывает покрытие большинства точек.

Для независимого от цели префикса перевод R -> R-prefix сохраняет равномерность. Поэтому замена M16 на M15 посредством независимого угадывания одного слагаемого имеет вероятность успеха одной попытки не выше 0.001330573 даже при идеальном остаточном решателе. Это не распространяется на неизвестный метод, который выбирает префикс информативно по координатам цели, и не является универсальной нижней границей времени. Для независимых повторных испытаний соответствующий оптимистичный штраф около 752 попыток; для m14 около 2.84e7.

## 3. Точная стоимость слепого дополнения

Пусть S есть сумма 15 выбранных точек, независимая от равномерного R. Проверка последнего слагаемого T=R-S успешна ровно при T in A. Поэтому вероятность одной попытки точно |A|/n, около 2^-236.8868734. Повторные испытания с независимыми равномерными целями дают геометрическое ожидание n/|A|. Для одной фиксированной цели распределение случайных префиксов может быть неравномерным; универсальное геометрическое ожидание для неё не утверждается.

Полный список формальных сумм восьми точек, даже после известных GLV-нормализаций, имеет K_8 ~ 2^137.60568 записей. Это размер списка коэффициентных кандидатов, не доказанный размер множества различных групповых сумм и не нижняя граница для всех методов meet-in-the-middle.

## 4. Условная, но конкретная стоимость перестановок

Рассмотрим исходный прямой идеал

    I_R = (X_1^D-1,...,X_16^D-1,S_17(X_1,...,X_16,x(R))).

Если имеется корректное разложение R с шестнадцатью различными x-координатами, перестановки дают ровно 16! различных корневых кортежей исходного идеала. Поскольку D делит p-1, каждый X_i^D-1 полностью раскладывается на различные линейные множители. Китайская теорема об остатках даёт:

    F_p[X_1,...,X_16]/(X_i^D-1) = product_(H^16) F_p.

Добавление S17 сохраняет факторы, где он равен нулю. Поэтому размерность полной фактор-алгебры I_R не меньше 16! при указанном условии.

16! = 20922789888000. Явный несжатый список 16 координат по 32 байта на кортеж занимает не менее 10712468422656000 байт, около 10.71 десятичных петабайт.

Подготовлен 256-битный PLANTED-свидетель с 16 различными x. Это точная демонстрация непустоты условия, НЕ решение независимо заданной цели и НЕ оценка delta16. Сумма перепроверена независимой проективной арифметикой. Проверка 5140 перестановок тестирует реализацию; вывод обо всех 16! следует из коммутативности и различия координат, а не из выборки.

Ограничение относится к явному перечислению всех упорядоченных ответов и построению полного стандартного базиса фактор-алгебры. Оно НЕ является универсальной нижней границей для Groebner-алгоритмов, поиска одного корня, сжатых представлений, симметрических координат или случайного выделения компоненты. При фиксированном m фактор m! также не доказывает ухудшения асимптотического показателя по n.

Проверен полином g(T)=product(T-x_i), degree16, g divides T^D-1. Эта точная запись убирает перестановки в случае различных x, но сама по себе не даёт алгоритма нахождения g по R. Повторяющиеся координаты требуют отдельной ветки и не должны молча отбрасываться. Симметризация суммирующих полиномов уже изучалась в литературе; новизна общего приёма не заявляется.

## 5. Контрольные эксперименты

Четыре кривые y^2=x^3+7 над простыми полями. Полные группы имеют простой порядок; это проверено перечислением точек и отдельной проверкой простоты.

- p=4159, n=4243, D in {6,18,42,54,66,126,198};
- p=16879, n=17107, D in {6,174};
- p=64303, n=63799, D in {6,42};
- p=257107, n=257869, D=6.

Все двенадцать выбранных конфигураций отражены в результатах. Подгруппы с большими D не добавлялись после просмотра результатов. Выбор исходных простых делался детерминированным поиском по публичным условиям; его журнал включён. Эти параметры НЕ образуют масштабно согласованное семейство для экстраполяции secp256k1.

Покрытие mA для m=1..16 вычислено исчерпывающе с помощью циклических битовых множеств по индексам полной группы. Для всех семи конфигураций на самом малом поле выполнена независимая сверка обычными Python-множествами. Полная таблица дискретных логарифмов использовалась только для ground truth и проверки, НЕ передавалась поисковому алгоритму. Её построение не выдаётся за практический быстрый метод разложения.

Поиск: случайные списки сумм восьми точек, L=ceil(sqrt(n)), общий левый список, по одному правому поиску на цель. Учитываются подготовка, неудачные цели, онлайн-сложения и проверка результата. Это контрольный generic 8+8 алгоритм, а НЕ S17/PKC-решатель.

На каждой конфигурации 64 равномерные цели, полученные до поиска независимо от факторбазы. На одном поле одинаковые цели переиспользованы между конфигурациями для сопоставимости. Поэтому всего 768 испытаний (конфигурация,цель), а не 768 независимых выборок. Суммарно 319 найденных и проверенных разложений, 526 представимых испытаний согласно исчерпывающему ground truth.

Каждый из 319 ответов независимо перепроверен проективным сложением и скалярным умножением, без использования аффинной арифметической реализации производителя.

Для восьми конфигураций покрытие M16 равно 100%. Контрольный поиск находил 32..42 ответа из 64, а не 100%: существование ответа не равняется успешности ограниченного алгоритма. На четырёх одноорбитных базах A=6 покрытие равно 817/n; результат согласуется с точной формулой 1+3m(m+1) при m=16.

BSGS выполнен отдельно как контроль стоимости решения исходного DLP на тех же целях. Он не решает ту же задачу факторбазного разложения, и сравнение счётчиков не представляется формальным equal-success сравнением двух методов разложения. Преимущество контрольного 8+8 метода в этих проверках не получено.

## 6. Проверка всей алгебраической цепочки

Для каждой конфигурации с достаточным числом ответов выбраны первые B+1 найденных соотношений. Все точки переведены в B столбцов GLV с коэффициентами +/-lambda^j. Публичная согласованность beta и lambda проверена скалярным умножением.

Сначала из C выбран ненулевой w с w^T C=0. Только затем испытательный стенд генерирует независимые случайные b_i. При фиксированном тестовом секрете k и уже полученных равномерных скалярах целей r_i положено a_i=r_i-b_i*k. Это эквивалентно равномерной генерации a_i,b_i при фиксированном k; поисковый алгоритм ранее видел только точки R_i, не r_i или k.

Вычислено k=-(w^T a)/(w^T b) mod n. Девять конфигураций восстановили тестовое значение; три конфигурации дали недостаточно ответов. Независимый валидатор проверил все матрицы, линейные комбинации настоящих точек и восстановление k. Получение соотношений не объявляется ускоренным.

## 7. Оставшиеся точные условия успеха

В варианте не более одного принятого соотношения на независимо размеченную цель, с B+1 соотношениями:

    T_total = C_pre + (B+1)*C_try/delta + C_LA

при независимых испытаниях и корректно определённой вероятности. Здесь delta есть вероятность успеха алгоритма в установленном бюджете, не просто вероятность существования разложения. Чтобы даже в оптимистичном учёте быть ниже необкалиброванного ориентира sqrt(n), потребуется C_try/delta <~ 2^111.47182, ещё до расходов подготовки и линейной алгебры. Это математический фильтр, НЕ практический бюджет компьютера.

Для покрытия определим rho(R)=число нормализованных формальных векторов веса <=16 с образом R, K=sum rho(R), S2=sum rho(R)^2. По Коши-Буняковскому:

    delta_existence >= K^2/(n*S2).

Например, доказанное S2<=2K^2/n обеспечило бы delta_existence>=1/2. Для настоящей secp256k1 такая оценка в этом проходе не доказана и не измерена. Даже её доказательство не обеспечило бы дешёвый поиск свидетеля.

Ближайший содержательный алгоритмический узел: найти один корректный свидетель для независимо заданной цели без материализации перестановочного семейства, с сохранением доли покрытых целей и полным учётом неудачных попыток. Возможные реализации через симметризацию и выделение одной компоненты являются исследовательскими кандидатами, а не принятыми быстрыми алгоритмами.
