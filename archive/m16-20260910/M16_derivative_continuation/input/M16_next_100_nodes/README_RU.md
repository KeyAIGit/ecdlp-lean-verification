# Продолжение M16: доказательства, поисковые контроли и 100 узлов

Начните с `RESEARCH_NOTE_RU.md`. Реестр всех ста узлов: `NODES_100_RU.md` и `nodes_100.json`.

## Готовые результаты

Нормовая карта описывает один неупорядоченный свидетель и позволяет восстановить знаки и кратности. Она не является быстрым алгоритмом поиска такого свидетеля для заданной secp256k1-точки. Целевой M16-решатель, нижняя граница покрытия и полная оценка стоимости остаются открытыми.

`certificate_suite.json`: 319 прежних контрольных свидетелей и 24 заранее построенных 256-битных шаблона. `independent_validation.json`: их независимая проверка.

`q2_benchmark.json`: настоящий поиск на 39 обычных целях и одна отдельная ветвь, 26 найденных разложений.

`q4_*.json`: настоящий поиск квадратсвободных q4-разложений на малых кривых. Шесть различных целей, 17 разных пар цель-свидетель; повторные запуски сохранены отдельно. `independent_search_validation.json` проверяет и ответы, и полноту малых множеств.

`quantitative_bounds.json`: точные границы покрытия, исключений и равномерного угадывания.

`usable_cube_polynomial.bin`: полный J над настоящим полем secp256k1, степень 94509. `usable_cube_roots.bin`: все его 94509 корней. Каждый элемент хранится в 32 байтах little-endian; коэффициенты идут от постоянного к старшему. Эти файлы являются математическими данными, не исполняемыми программами.

`usable_polynomial_validation.json`: независимая перепроверка квадратичности всех 188174 кубических координат и точное полиномиальное равенство J*K=T^188174-1. Умножение полиномов здесь разделяет backend с производителем, что явно отмечено.

`frobenius_split_check.json`: заранее построенный пример исключительного механизма над квадратичным расширением.

`attempt_limits.json`: сохраненные неудачные и цензурированные попытки. Таймаут не является доказательством отсутствия решения.

## Проверка готового пакета

Из каталога пакета:

```bash
sha256sum -c manifest.sha256
python independent_validate.py
python independent_search_validate.py
python norm_bridge.py norm_secp_distinct.json
```

Основной сертификатный модуль использует стандартный Python. Независимый полиномиальный валидатор и q4-контроль используют SymPy. Простота p и допустимость поля являются предпосылками математической постановки: программа не является универсальным сертификатором простоты произвольного переданного p.

## Воспроизведение расчетов

```bash
python quantitative_bounds.py
python run_certificate_suite.py
python run_q2_benchmark.py
python q4_symbolic_probe.py 97 6 0
python q4_symbolic_probe.py 163 9 1 usable
python frobenius_split_check.py
```

q4-команда без `usable` для p163,D9,index1 ранее не завершилась в окне инструмента. Она не входит в быстрые проверки пакета. Повторные численные запуски изменяют времена в отчетах, поэтому прежний манифест после регенерации таких файлов закономерно не совпадет.

Для полной регенерации полинома J используется дерево произведений. Чистый Python-вариант точен, но может быть медленным. В текущем окружении ускоренный вариант использовал уже установленную GMP:

```bash
gcc -O2 -fPIC -shared kronecker_gmp.c -lgmp -o kronecker_gmp.so
python build_usable_polynomial.py roots
python build_usable_polynomial.py build
python validate_usable_polynomial.py
```

В архиве есть C-исходник, но нет готовой платформозависимой библиотеки. Этот этап не нужен для чтения уже построенных коэффициентов или проверки обычных малых сертификатов.

Результаты относятся к локальному исследовательскому проходу. Lean не запускался, GitHub не изменялся. Статусы DERIVED в реестре означают аналитические выводы с письменными доказательствами/обоснованиями, не машинно формализованные теоремы. Статусы OPEN не считаются закрытыми узлами.
