## 1. Исходные объекты

Пусть

```
p = 2^256 - 2^32 - 977
n = 0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEBAAEDCE6AF48A03BBFD25E8CD0364141
D = 564522
E: y^2 = x^3 + 7 over F_p
H = {x in F_p*: x^D = 1}
A = {(x,y) in E(F_p): x in H}
```

Проверенные входные числа: `|A|=567054`, число пригодных x равно 283527, число шеститочечных орбит равно `B=94509`. Параметры p и n и их простота здесь принимаются из стандартных параметров и исходного состояния проекта; новый сертификат простоты не строился.

Обозначим `mA` множество сумм ровно m точек из A, с повторениями, и `delta_m=|mA|/n`. Факторбаза замкнута относительно отрицания и отображения `phi(x,y)=(beta*x,y)`, где beta является нетривиальным кубическим корнем единицы. Горизонтальная прямая через P пересекает кривую в P,phi(P),phi^2(P), поэтому сумма этой тройки равна O.

Из исходного проверенного подсчета:

```
K_m = sum_{j=0}^{min(B,m)} binom(B,j) * 6^j * binom(m+j,2*j), m>=2
|mA| <= K_m
K_13/n = 8.690579035429138e-13
K_14/n = 3.519864537451805e-8
K_16/n = 47.15422998115776
```

K_m считает формальные коэффициентные векторы, а не различные точки. Последнее число является средним числом таких формальных представлений на цель, а не вероятностью разложения.

## 2. Точная нормовая карта

Пусть q четно, `2<=q<=16`, `s=q/2`, а цель `R=(r,z)` имеет `r notin H`. Особые цели рассмотрены отдельно ниже. Ищем полиномы a,b над F_p:

```
deg(a) <= s
b monic, deg(b)=s-1
a(r) = z*b(r)
g(X) = ((X^3+7)*b(X)^2-a(X)^2)/(X-r)
```

Тогда g автоматически со старшим коэффициентом 1, степени q. Нужны два условия:

```
gcd(g,b)=1
g divides (X^D-1)^q
```

Критерий принадлежности допускает кратные корни. Требование `g divides X^D-1` задает только отдельную карту различных x и не заменяет общий критерий.

### Теорема 1: корректность и полнота карты

При указанных условиях карта находится во взаимно однозначном соответствии с неупорядоченными мультимножествами q точек из A, сумма которых R и которые не содержат одновременно P и -P. Повторения одной и той же точки разрешены.

Если alpha является корнем g кратности mu, соответствующее слагаемое:

```
P_alpha = (alpha, -a(alpha)/b(alpha))
```

с кратностью mu.

### Доказательство прямого направления

Все корни g лежат в H, поскольку `X^D-1` полностью распадается над F_p и имеет простые корни. Условие взаимной простоты делает b(alpha) ненулевым. Нормовое равенство дает квадрат нужного значения y. На secp256k1 нет рациональных точек порядка 2, поэтому это y ненулевое.

Рассмотрим функцию `f=a(x)+y*b(x)` на E. Она имеет полюс ровно q+1 в O: старший член y*b имеет порядок полюса `3+2(s-1)=q+1`, а a имеет порядок не выше q. В точке -R функция обращается в ноль. При каждом alpha ровно одна из двух ветвей y дает ноль. Другая ветвь ненулевая, поэтому кратность корня нормы совпадает с кратностью нуля f на выбранной ветви. Так как `r notin H`, корень r отделен от g.

Следовательно,

```
div(f) = sum_alpha mu_alpha[P_alpha] + [-R] - (q+1)[O].
```

Связь группы точек с группой классов дивизоров степени ноль дает `sum mu_alpha*P_alpha = R`.

### Доказательство обратного направления

Для заданного мультимножества без сокращающихся пар дивизор выше является главным. Пространство функций с этим дивизором одномерно. Базис `L((q+1)O)` состоит из

```
1,x,...,x^s, y,xy,...,x^(s-1)y.
```

Это дает f=a+y*b. Старший коэффициент b ненулевой из-за точного порядка полюса; нормируем его к 1. Получаем единственный нормированный f. Норма имеет вид `-(X-r)*g`, где g есть произведение `(X-x(P_i))`, с кратностями. Общий корень b и g означал бы наличие обеих ветвей P и -P в дивизоре, что исключено.

Функция определена над F_p: исходный дивизор рационален, а нормирование делает функцию единственной, поэтому Фробениус ее фиксирует. Эквивалентно, линейная система условий на коэффициенты над F_p имеет одномерное ядро над алгебраическим замыканием и такое же ядро над F_p.

Основные факты о дивизорах и Римане-Рохе являются стандартными [S1]. Приведенные условия, исключения и количественное применение к текущей факторбазе являются выводом этого прохода; общая идея не объявляется новой.

### Число параметров и стоимость проверки

Всего q+1 коэффициент у a и b, один фиксируется нормировкой и один линейным условием в -R. Остается q-1 свободный коэффициент. Для M16 их 15.

Это количество параметров, а НЕ оценка сложности поиска. Проверить уже заданные коэффициенты можно без раскрытия `X^D` и без S17: вычислить `h=(X^D-1) mod g`, затем `h^q mod g`, найти обратный к b по модулю g, факторизовать полином степени не больше 16 и проверить сумму. Проверка готового ответа не является генератором ответа.

## 3. Полнота для M16 и потеря покрытия одной карты

В любом M16-представлении удаляем все пары P,-P. Остается четное число слагаемых q от 0 до 16. При q>0 остаток описывается одной из восьми нормовых карт. Недостающие слагаемые затем возвращаются известными противоположными парами.

Для O достаточно восьми таких пар. Если R принадлежит A, готово представление R плюс пять известных нулевых GLV-троек. Эти специальные цели не требуют нормового решателя.

Если представить R через M16 можно, но карта q=16 без сокращений не имеет решения, то какое-то исходное представление содержит противоположную пару. Поэтому R находится в 14A. Получаем:

```
0 <= delta_16 - delta_C16 <= K_14/n = 3.519864537451805e-8,
```

где C16 включает нормовую карту и обработанные специальные цели.

Это абсолютная разность долей среди всех n целей. Без нижней границы delta_16 нельзя переводить ее в относительный процент потерянных разложимых целей. В частности, из нее НЕ следует, что разложимы 99.999996% всех точек.

### Карта различных x

Если разложение содержит одинаковые x, то есть либо одинаковые точки, либо противоположная пара. Все соответствующие цели входят в `2A+14A`. Даже 14A входит в это множество: заменить одно P в 14-членной сумме на `2P-P`.

В формальной решетке GLV норма `(u,v)` равна `max(|u|,|v|,|u-v|)`. После вычитания удвоенной единицы наилучшее уменьшение нормы равно:

- -2 для нуля;
- 0 для единичного веса;
- 2 для шести векторов вида 2*unit;
- 1 для остальных шести векторов веса 2;
- 2 для веса не меньше 3.

Поэтому для m=16 точный размер формального объединения переводов шара веса 14 равен

```
W_16 = K_16 - 6^15*binom(B,15) - [t^16](1+6*t+6*t^2)^B.
```

Отсюда абсолютная потеря покрытия карты различных x не больше

```
W_16/n = 0.019955379407882636.
```

Локальная классификация проверена на 3169 векторах; формула дополнительно сверена прямым перечислением двух орбит и независимым полиномиальным возведением в степень. Полный аналитический аргумент относится ко всем B, а не следует из этих конечных тестов.

## 4. Фробениус: где могут появиться нерациональные решения

Рассмотрим ту же нормовую карту над алгебраическим замыканием, но с `g divides (X^D-1)^q` и `gcd(g,b)=1`. Все x слагаемых лежат в F_p. Каждое y лежит в F_(p^2): для пригодных координат оно рационально, для непригодных Фробениус меняет его знак.

Разделим сумму на рациональную и нерациональную части:

```
S_rat + S_non = R.
```

Применение Фробениуса дает `S_rat-S_non=R`, следовательно `2*S_non=O`.

В E(F_(p^2)) нет ненулевой точки порядка 2. Действительно, отсутствие такой точки над F_p означает отсутствие корней у кубического `X^3+7`; кубический полином тогда неприводим. Неприводимый полином степени 3 не приобретает корней в расширении степени 2. Поэтому `S_non=O`, а `S_rat=R`.

При отсутствии противоположных пар нерациональная ненулевая часть не может состоять из одной или двух точек. Ее длина не меньше трех. Для q=16 рациональных слагаемых тогда не больше 13. За счет замкнутости A относительно GLV любую ненулевую более короткую сумму можно дополнить до 13 слагаемых. Получаем:

```
R != O and a nonrational noncancelling M16 certificate exists  =>  R in 13A.
```

Таким образом, доля целей, для которых возможно такое расширение поля, не больше `K_13/n=8.690579035429138e-13`. Вне этого исключительного множества любой нормированный сертификат указанной карты над замыканием фактически определен над F_p.

Это не положительная оценка числа решений, не их эффективный поиск и не универсальная теорема о произвольных представлениях S17. Условия нормовой карты, включая взаимную простоту, существенны.

Исключительный механизм не фиктивный: `frobenius_split_check.py` строит пример q=6 над F_(163^2). Три рациональные точки складываются в R=(89,1), еще три нерациональные GLV-точки дают O. Полная H-система принимает сертификат над расширением, а фильтр пригодных координат его отбрасывает. Пример заранее построен из слагаемых и не используется как оценка частоты.

## 5. Полином пригодной факторбазы: построение на настоящем поле

Пусть `M=D/3=188174`, а

```
V = {u in F_p: u^M=1 and chi(u+7)=1}
J(T) = product_{u in V}(T-u).
```

Тогда

```
F_U(X)=J(X^3)
deg J=94509
deg F_U=283527
```

и корни F_U являются ровно пригодными x факторбазы. Эквивалентно,

```
J(T)=gcd(T^188174-1, (T+7)^((p-1)/2)-1),
```

с нормировкой старшего коэффициента. Последняя запись является тождеством, а не сообщением о запуске большого символьного gcd: использовано дерево произведений по явно вычисленным корням.

Замена `g | (X^D-1)^q` на `g | F_U(X)^q` сохраняет все нужные рациональные разложения. В карте различных x используются первые степени. Нельзя подменять это отображение независимым кубированием переменных с потерей фаз: здесь сохраняются сами координаты x, а J(X^3) задает только точную принадлежность исходной факторбазе.

### Существенная оговорка о разреженности

У настоящего J ненулевые ВСЕ 94510 коэффициентов. Поэтому F_U содержит 94510 ненулевых членов, тогда как исходный `X^D-1` только два. В малом успешном примере фильтр равен `X^6+X^3+1`. Более низкая степень на настоящем поле сопровождается намного более плотным полиномом; скорость малого примера не переносится автоматически.

## 6. Не только проверка свидетелей: запущенные поисковые алгоритмы

### q=2: полностью заданный одно-параметрический поиск

При q=2 имеем b=1 и `a(X)=z+t(X-r)`. Тогда

```
g_t(X)=X^2+(r-t^2)X+(r^2+r*t^2-2*z*t).
```

Положим `X^D mod g_t = A_D(t)*X+B_D(t)`. Коэффициент A_D имеет точную степень `2D-2`: в рекурсии член с t^2 повышает степень на 2 и его старший коэффициент не сокращается. Для настоящего D это 1129042.

Чтобы учесть также повторную точку, вычисляются два коэффициента `(X^D-1)^2 mod g_t`, их gcd и пересечение с `t^p-t`. По корням gcd восстанавливаются точки. Программа получает только p,D,R, без готового разложения, списка факторбазы или скалярной метки цели.

39 обычных контрольных целей проверены полностью, еще одна попала в отдельную специальную ветвь. Найдено 26 разложений. Полное совпадение со вторым перебором дополнений проверено и для успехов, и для пустых множеств. Это полный поиск q=2 в заявленной карте, не решение M16.

В контрольных D=18,42,126,174 максимальные степени записанных уравнений были 70,166,502,694. Уменьшение количества параметров не сделало эти степени константой. Простая проверка дополнений с готовой таблицей на этих малых задачах дешевле; расходы подготовки таблицы отдельно от онлайн-измерения и не скрываются в формальном сравнении.

### q=4: три параметра и реальный символьный решатель

Использовано b=X+b0, a=a0+a1*X+a2*X^2, где a0 исключается условием в -R. Четыре коэффициента остатка полинома принадлежности по модулю g дают систему от a1,a2,b0. SymPy вычисляет grevlex-базис и затем точные решения над F_p. Это полный материализующий базисы контрольный решатель, не предполагаемый будущий масштабируемый алгоритм одного корня.

Для p=97,D=6 пригодны все шесть координат H. На трех независимых целях получены 4,4,3 квадратсвободных разложения. Для p=163,D=9 пригодны шесть из девяти координат; фильтр `F_U=X^6+X^3+1`. На трех независимых целях получены 2,2,2 разложения.

На одной и той же цели p=163,D=9,index=1:

- исходные четыре уравнения имеют степень 12; вычисление не завершилось за 45-секундное окно инструмента;
- отфильтрованные четыре уравнения имеют степень 6; grevlex завершился за 1.762 секунды, последующее выделение решений примерно за 0.006 секунды;
- повторный проход подтвердил два ответа.

Это цензурированное сравнение, а не измеренный точный коэффициент ускорения. Завершившиеся отфильтрованные прогоны на шести целях дали времена grevlex примерно от 1.73 до 1.90 секунды. Все 17 различных пар (цель,свидетель) проверены независимой арифметикой, а полнота ответов на этих малых задачах проверена исчерпывающим перечислением различных x и знаков.

Лемма раздела 4 объясняет дополнительную тонкость: для q=4 и цели вне A нерациональные несокращающиеся ответы вообще невозможны. Поэтому на этих примерах фильтр может ускорять получение уже логически следовавших ограничений, а не обязательно удалять настоящие дополнительные корни. Выходная степень базиса 2 НЕ называется solving degree.

## 8. Что точно не сработает как обоснование ускорения

### Равномерное угадывание 15 коэффициентов

Для каждой обычной цели существует p^15 нормированных параметрических наборов. Число сертификатов не больше числа неупорядоченных мультимножеств 16 точек факторбазы. Поэтому при равномерной цели вне особых ветвей и равномерных коэффициентах

```
Pr[success] <= binom(567054+15,16) / ((n-567054-1)*p^15)
log2 Pr[success] <= -3834.4398095280235.
```

Это опровергает именно равномерное угадывание. Адаптивный структурный выбор коэффициентов этим рассуждением не запрещен.

### Интерполяция по пятнадцати заранее выбранным точкам

Пятнадцать нулей из факторбазы плюс -R определяют функцию с одним оставшимся нулем. По групповому закону его точка равна R минус сумма пятнадцати выбранных точек. Таким образом, этот способ эквивалентен прежнему слепому дополнению, а не новой вероятностной лазейке. Для независимого префикса и равномерной цели вероятность попадания остатка в A равна |A|/n.

### Другие необоснованные переходы

Малое число коэффициентов не дает малую степень устранения. Быстрое умножение полиномов не решает систему ограничений. Одно значение выходной степени базиса не измеряет максимальную промежуточную степень. Исключение перестановок не доказывает квадратно-корневой или субэкспоненциальной оценки. Переформулировка в задачу кодов не является новым универсальным решателем: связь ECDLP с кодированием уже исследовалась [S3].

## 9. Полный критерий стоимости остается незакрытым

Для одного принятого соотношения на отдельную случайно размеченную цель:

```
T_total = C_pre + (B+1)*C_try/delta_alg + C_LA.
```

Здесь измеренный компонент C_pre теперь включает построение J, но не всю возможную подготовку будущего решателя. delta_alg является вероятностью НАЙТИ ответ за установленный вычислительный бюджет, а не delta_16 или средним K16/n.

Остаются неизвестными: эффективная процедура выбора коэффициентов a,b; ее стоимость и память на q16; сохранение вероятности успеха; положительная нижняя граница покрытия для настоящей факторбазы; стоимость линейной алгебры и равноправное сравнение полной процедуры. Ни один неудачный запуск SymPy не является доказательством отсутствия другого алгоритма.

Точный следующий узел в подготовленном реестре:

```
M16-CB-081 / ONE_CERTIFICATE_SEARCH
```

Его вход: фиксированный J, независимо заданный R, нормативные ограничения на a,b,g. Выход: один проверяемый сертификат или честно учтенный неуспех. Цель: доказуемо или воспроизводимо улучшить C_try/delta_alg с учетом подготовки, памяти и масштаба. Дополнительное переписывание тождеств без улучшения этой величины не будет считаться закрытием данного узла.
