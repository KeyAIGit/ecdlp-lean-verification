# Продолжение реестра

Исходный реестр 001..100 сохранен в input, не переписан.

| Узел | Результат | Статус |
|---|---|---|
| 101 | Эквивалентность `g|F^q` и `g|F*g'` при p>q | DERIVED_AND_CHECKED |
| 102 | Контрпример без условия p>q | CHECKED |
| 103 | Невырожденный якобиан пространства поддержек, включая кратные корни | DERIVED_AND_CHECKED |
| 104 | Формула детерминанта для F=X^D-1 | DERIVED_AND_CHECKED |
| 105 | Полный ранг q-1 в допустимой нормовой карте | DERIVED_AND_CHECKED |
| 106 | Нулевой якобиан степенной записи на квадратсвободных решениях | DERIVED_AND_CHECKED |
| 107 | Новые полные малые q4-поиски с повторениями | CHECKED_TINY_ONLY |
| 108 | Явное частное H: меньше степень, больше переменных | CHECKED_NOT_GENERAL_GAIN |
| 109 | Практический выигрыш на более крупных q4/q6 | OPEN_RIGHT_CENSORED |
| 110 | Дешевый поиск M16 для независимо заданного R | OPEN |

DERIVED не означает принятие доказательства ядром Lean. CHECKED_TINY_ONLY не дает экстраполяции на 256 бит. Общий барьер не закрыт.
