# Продолжение M16: поддержка через производную

Главный файл: `RESEARCH_NOTE_RU.md`. Машиночитаемая сводка: `RESULTS.json`.

Положительный результат: точная замена `g | F^q` на `g | F*g'` при p>q, полный якобианов ранг на допустимой нормовой карте. Полное множество решений этой карты сохраняется, включая повторяющиеся точки. Это не оценка стоимости поиска M16 и не решение ECDLP.

## Воспроизведение

Python 3.10+ и SymPy; точная использованная версия в `requirements.txt`.

```
python -m pip install -r requirements.txt
python check_derivative_structure.py
python derivative_probe.py --p 97 --D 3 --q 4 --index 1 --encoding derivative
python validate_searches.py
```

Последний скрипт проверяет полные множества решений в сохраненных завершенных малых прогонах, независимо от арифметики поисковой программы. `check_derivative_structure.py` проверяет 5043 малых полинома и 24 ранее построенных 256-битных сертификата. Для всех 15 направлений одного M16-образца используется отдельное прямое дифференцирование через двойственные числа.

`run_benchmarks.py` повторяет явно сохраненный план, включая незавершившиеся контрольные попытки. Каждый процесс имеет технический бюджет 60 секунд; тайм-аут фиксируется как `RIGHT_CENSORED`, а не как отсутствие решения. Полный повтор всего плана не требуется для проверки уже сохраненных свидетельств.

Все 256-битные образцы являются PLANTED. Малые поисковые цели выбираются по SHA256 до поиска, независимо от факторбазы. Исчерпывающее перечисление находится только в валидаторе и не передается поисковому решателю.

Каталог `input/M16_next_100_nodes` сохраняет исходный пакет. Его манифест перепроверен; журнал `results/input_manifest_replay.log`. Исходная большая факторбаза не изменялась и не регенерировалась.

Граница результата: новые q16-разложения независимо заданных точек secp256k1 не найдены; сложность глобального решения не доказана. Lean и GitHub в этом проходе не изменялись.
