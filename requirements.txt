# Optional Python dependencies for the auxiliary scripts.
#
# The Lean proof build uses the pinned Lean/Mathlib toolchain. Most metadata
# generators use the Python standard library, but full CI ALSO runs symbolic
# certificate checks with their pinned experiment requirements (for example
# experiments/glv_semaev_symmetry/requirements.txt). Thus full CI is not free of
# Python dependencies. Model SDKs below are optional and are not proof authorities.
# Install only the dependencies required for the specific workflow being run.
#
#   sympy      — offline CAS certificates (scripts/certify.py, pratt_certificate.py,
#                scripts/certs/*): independent-verification of division-polynomial /
#                torsion / Pratt-factor identities before a Lean transcription.
#   anthropic  — strong-model proposer (scripts/agent_prove.py, agent_day.py,
#                certify.py, explore_pipeline.py); reads ANTHROPIC_API_KEY from env.
#   openai     — OpenAI-compatible clients for Featherless / DeepSeek tiers
#                (scripts/explore_pipeline.py, hypothesis_explorer.py). The Featherless
#                tier is dead from CI (verified 2026-07-15: HTTP 403 / Cloudflare 1010 bot-block
#                of GitHub runners, key valid); may still work from the warm server. See SETUP.md.
#
# Floors, not exact pins: these scripts are auxiliary and API-surface-stable across
# these ranges. The reproducible artifact is the Lean toolchain (lean-toolchain,
# lakefile.toml, lake-manifest.json), not this file.
